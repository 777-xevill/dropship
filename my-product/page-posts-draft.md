## Post 3: Why water-based?
```
💧 পানি-ভিত্তিক লুব্রিকেন্ট কেন বেছে নেবেন? ৩টা কারণ:

১. পানিতে সহজে ধুয়ে যায় — আঠালো ভাব থাকে না
২. কাপড় বা বিছানায় দাগ পড়ে না
৩. তেল-ভিত্তিক জিনিস (যেমন নারকেল তেল, ভ্যাসলিন) ল্যাটেক্স কনডমকে দুর্বল করে দিতে পারে — পানি-ভিত্তিক লুব্রিকেন্টে সেই সমস্যা নেই

ঘরোয়া তেল দিয়ে কাজ চালানোর চেয়ে সঠিক জিনিসটা ব্যবহার করাই নিরাপদ।
```
*Point 3 is general knowledge about water-based vs oil-based lubes. Before posting, read your bottle's label for a "condom compatible" line.*

## Post 4: What's normal as we age
```
🌸 একটা স্বাভাবিক বিষয়, যা নিয়ে কেউ কথা বলে না

বয়স বাড়ার সাথে সাথে, বিশেষ করে ৪০-এর পর, শরীরের স্বাভাবিক আর্দ্রতা কমে যাওয়া খুবই সাধারণ।
বাংলাদেশের গবেষণাতেও দেখা গেছে, মেনোপজের পর অনেক নারীই শুষ্কতাজনিত অস্বস্তির কথা জানিয়েছেন।

এটা লজ্জার কিছু না। অনেক দম্পতিই এর সহজ সমাধান হিসেবে পানি-ভিত্তিক লুব্রিকেন্ট ব্যবহার করেন।
সমস্যা বেশি হলে বা ব্যথা থাকলে অবশ্যই একজন ডাক্তারের পরামর্শ নিন।
```

## Post 5: Safe-use note
```
✅ প্রথমবার ব্যবহারের আগে ছোট্ট একটা কাজ

যেকোনো নতুন পণ্য ব্যবহারের আগে হাতের ত্বকে অল্প একটু লাগিয়ে কিছুক্ষণ অপেক্ষা করুন।
জ্বালা, লালচে ভাব বা চুলকানি হলে ব্যবহার করবেন না।

আমরা "১০০% নিরাপদ" বা "কোনো পার্শ্বপ্রতিক্রিয়া নেই" বলি না — কারণ প্রত্যেকের ত্বক আলাদা।
সৎ থাকাটাই আমাদের নীতি। 🌿
```

## Post 6: 3 things to check when buying
```
🔍 অনলাইনে লুব্রিকেন্ট কেনার আগে এই ৩টা জিনিস মিলিয়ে নিন:

১. বোতলের সিল অক্ষত আছে কিনা
২. মেয়াদ (expiry date) লেখা আছে কিনা
৩. জেলের ঘনত্ব — পানির মতো একদম পাতলা হলে সন্দেহ করুন

আমাদের কাছ থেকে নিলে পণ্য হাতে পেয়ে, দেখে তারপর টাকা দেবেন। পছন্দ না হলে নেবেন না।
```

# Things to make by hand (free web tools)

## scene_poster_hero  (4:5)
1. Open a free image tool (Gemini app: gemini.google.com | Qwen Chat: chat.qwen.ai | Copilot).
2. Upload: upload_these/poster_hero_ref1.png, upload_these/poster_hero_ref2.jpg
3. Paste this prompt (ask for 4:5 vertical):

```
the person from image 1 holding the product from image 2 out toward the camera with a confident smile, wearing a teal embroidered cotton kurta paired with a cream and blue floral printed dupatta draped over the shoulder, clean bright studio background in the product's colours, commercial photo, vertical 4:5. Keep the person's face, skin tone, hair and body exactly the same as in image 1 (same identity). Keep the product exactly as in image 2: same shape, colours, cap and label design. Photorealistic, natural skin texture, real smartphone photo quality. No text, no captions, no watermark.
```
4. Save the result into inbox/ as  scene_poster_hero.png  and run the command again.
